# Syntengro Vision Web Hub

Professional B2B landing page, multi-cloud digital hub, and client acquisition portal for Syntengro Vision.

## Architecture & Tech Stack
* **Frontend:** HTML5, Tailwind CSS (CDN)
* **Version Control:** Git & GitHub (`Syntengro-Vision/syntengro-vision-web`)
* **Target Audience:** Small businesses, medical, legal, and local professional offices requiring IT modernization and security hardening.

## Core Sections
* **Hero Section:** Value proposition and primary call to action.
* **Services Grid:** Overview of IT Modernization, Multi-Cloud Architecture, and Security & Compliance.
* **Contact Hub:** Secure client communication routing.
